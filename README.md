# Sentivra AI

### Your Mental Health Companion

Sentivra is an AI-powered emotional wellness platform designed to provide a safe, intelligent, and private space for people to express their thoughts, understand their emotions, and build healthier mental habits.

---

## Overview

Mental health support should be accessible, private, and available whenever needed.

Sentivra combines modern AI technology with thoughtful design to create a supportive environment where users can:

* Express emotions freely
* Track emotional well-being
* Receive personalized guidance
* Build healthy habits over time
* Access support anytime, anywhere

---

## Features

### Emotion-Aware Experience

Interactive mood slider allowing users to express how they feel in real time.

### Personalized Guidance

AI-driven conversations tailored to individual emotional states and needs.

### Privacy First

Built with user trust and confidentiality as core principles.

### 24/7 Availability

Support is available whenever users need someone to listen.

### Emotional Growth Tracking

Monitor emotional patterns and develop healthier coping strategies.

### Modern User Experience

Clean Apple-inspired interface with responsive design and smooth animations.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/sentivra-ai.git
```

### Navigate to Project

```bash
cd sentivra-ai
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
